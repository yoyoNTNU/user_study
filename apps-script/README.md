# Google Apps Script 部署步驟(把回覆寫進 Google 試算表)

只需要做一次,大約 5 分鐘。

## 1. 建立 Google 試算表
1. 到 [Google Sheets](https://sheets.new) 建立一份新的試算表,取個名字,例如「換裝研究_回覆」。
2. 先不用手動加欄位,程式第一次收到資料時會自動建立表頭。

## 2. 貼上程式碼
1. 在試算表上方選單:**擴充功能 → Apps Script**。
2. 把打開的編輯器裡預設的程式碼全部刪除,貼上這個資料夾裡 `Code.gs` 的內容。
3. 按上方儲存(磁片圖示)。

## 3. 部署成 Web App
1. 右上角「部署」→「新增部署作業」。
2. 選取類型:**網頁應用程式**。
3. 設定:
   - 說明:隨意(例如 v1)
   - 執行身分:**我**(你的帳號)
   - 誰可以存取:**所有人**(這樣靜態網站才能匿名送資料進來)
4. 按「部署」,第一次會要求你授權(Authorize access),照畫面點下去允許即可。
5. 完成後會給你一個網址,長得像:
   ```
   https://script.google.com/macros/s/AKfycb.../exec
   ```
   把這個網址整個複製起來。

## 4. 貼到網站設定
打開專案裡的 `config.js`,把 `SCRIPT_URL` 換成你剛剛複製的網址:

```js
SCRIPT_URL: "https://script.google.com/macros/s/AKfycb.../exec",
```

## 5. 測試
1. 直接把上面那個網址貼到瀏覽器打開,應該會看到 `{"status":"ok","message":"Apps Script is running"}`,代表部署成功。
2. 打開你的網站作答一組後,回到 Google 試算表確認 `Responses` 分頁有沒有出現新的一列資料。

## 之後修改程式碼要注意
如果你之後又編輯了 `Code.gs`,記得要「部署 → 管理部署作業 → 編輯(鉛筆圖示)→ 版本選新版本 → 部署」,
不然網址雖然沒變,但跑的還是舊程式碼。

## 常見問題
- **看不到 Responses 分頁 / 沒有資料**:先確認「誰可以存取」是設成「所有人」,而不是「我自己」。
- **想要用不同分頁區分不同批次的參與者**:可以把 `Code.gs` 裡 `getSheetByName("Responses")` 改成依日期或其他規則命名。
- **想限制只有特定人能填**:目前設計是完全匿名、任何人都能送資料進來(no-cors 送出,前端無法讀回應),
  如果需要驗證身分,建議另外在網站前端加一個簡單的通關密碼判斷,而不是改動這裡的存取權限。
